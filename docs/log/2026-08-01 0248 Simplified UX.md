# 2026-08-01 0248 Simplified UX

## TL;DR
- What changed: Simplified the first-use, toolbar, sidebar, import, room creation,
  and photo-attachment experience after a screenshot-based UX review.
- Why: The core room → item → photo workflow was obscured by secondary document
  and file-management controls.
- What didn't work: The fixed print canvas still requires horizontal exploration
  at very narrow widths; preserving the exact printed page remains intentional.
- Next: Review the revised flow with a real project and attach representative
  field photos.

---

## Full notes

- New punch lists start blank instead of loading the historical five-page sample.
- Add Room is now a primary toolbar action and focuses the newly created room.
- Empty state has two choices: add a room or import notes.
- Help and import are shorter and cannot remain open together.
- Sidebar document settings and maintenance tools are collapsed by default.
- Photo targets support keyboard activation and clearer accessible names.
- Laptop-width sidebar behavior no longer pushes the fixed document off canvas.
- Audit evidence is in `docs/audit/2026-08-01-ux-review/`.
- `npm.cmd run lint` and `npm.cmd run build` pass.
